The shortest path is a GitHub release installer. After install, Polyflo lives in the system tray — there is no always-on window.

## Before you begin

- **Windows:** Windows 10 or 11 with WebView2 (pre-installed on current Windows)
- **macOS:** macOS 10.15 or later
- A [Sarvam API key](https://dashboard.sarvam.ai/). Sarvam offers [trial credits](https://www.sarvam.ai/voice-to-text); speech-to-text is billed per second.

<Steps>
  <Step title="Download the installer">
    Open the latest [GitHub release](https://github.com/Crisiswastaken/PolyFlo/releases) and choose your platform:

    - **Windows:** `Polyflo_*_x64-setup.exe` (NSIS installer)
    - **macOS (Apple Silicon):** `Polyflo_*_aarch64.dmg`
    - **macOS (Intel):** `Polyflo_*_x64.dmg`
  </Step>
  <Step title="Install and launch">
    <Tabs>
      <Tab title="Windows">
        Run the `.exe` installer. Launch Polyflo from the Start menu. It appears in the **system tray**.
      </Tab>
      <Tab title="macOS">
        Open the `.dmg` and drag Polyflo into Applications. Launch it from Applications or Spotlight. It appears in the **menu bar**.

        Grant **Accessibility** when macOS asks, so Polyflo can paste into other apps. You can also enable it later in System Settings → Privacy & Security → Accessibility.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Add your Sarvam API key">
    If no key is saved, Settings opens automatically. Paste the key into **API Key** and leave the field — Polyflo saves it to the OS credential manager.

    The helper text should read **Saved locally — verified**. Details are in [API key](/api-key).
  </Step>
  <Step title="Dictate once">
    Click into any text field. Hold the default hotkey, speak a short sentence, then release:

    - Windows: `Ctrl+Shift+Space`
    - macOS: `Cmd+Shift+Space`

    A small overlay shows listening, then processing. The transcript should paste into the focused field.
  </Step>
</Steps>

## If paste does not happen

Polyflo always writes the transcript to the clipboard first. If auto-paste is blocked, it shows a notification so you can paste with `Ctrl+V` / `Cmd+V`. See [Troubleshooting](/troubleshooting).
