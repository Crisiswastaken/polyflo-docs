You do not pick a language before you speak. In **Transcribe** mode, Saaras v3 detects the language (including mixed utterances) and returns text in the script it heard.

**Translate** mode still accepts those languages as input and pastes **English**.

## Supported languages

## Code-mixing

Saaras v3 is built for mixed speech (for example Hindi + English in one sentence). Speak the way you normally would; you do not need a separate “Hindi mode.”

## What Polyflo does not do

- It does not expose Saaras `verbatim`, `translit`, or `codemix` output modes in Settings — only Transcribe and Translate.
- It does not let you force a `language_code`. Requests send `unknown` so the model auto-detects.
- It does not add AI punctuation cleanup or a custom dictionary. The pasted text is the model transcript (or its English translation).
